# Rock Paper Scissors

A classic Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript as part of the Odin Project Foundations curriculum.

[Play the game here on: https://akk-hrt.github.io/Odin-Rock_Paper_Scissors/](https://akk-hrt.github.io/Odin-Rock_Paper_Scissors/)

## Overview

This project implements an interactive Rock Paper Scissors game where players compete against the computer. The game is played across multiple rounds until either the player or computer wins 5 times.

## Features

- Interactive Gameplay: Press buttons to make your choice (rock, paper, or scissors).
- Score Tracking: Real-time display of both player and computer scores.
- Round Feedback: Immediate visual feedback showing both choices and round results.
- Win Detection: Game automatically declares a winner when either side reaches 5 wins.
- No Dependencies: Pure vanilla JavaScript with no external libraries.

## How to Play

1. Press one of the three buttons: Rock, Paper, or Scissors
2. The computer makes a random choice
3. The winner of the round is determined by these rules:
    - Rock beats Scissors
    - Scissors beats Paper
    - Paper beats Rock  
4. If both players choose the same option, it's a draw and scores don't change.
5. First to win 5 rounds wins the game!
